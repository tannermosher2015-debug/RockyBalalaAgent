# Rocky Balala — Maui Real Estate Agent

Single-file marketing site for **Rocky Balala**, a Wailuku-based real estate agent with
Island Wide Realty (Hawaii R(S) license RS-82410), serving Maui island-wide.

- **Stack:** one self-contained `index.html` — no build step, no framework. Inline critical
  CSS, deferred JS, async Google Fonts (Cormorant Garamond · Jost · Pinyon Script).
- **Design:** dark-luxury real estate — deep navy + gold + warm cream, a gold horizon-arc
  motif, art-directed Maui SVG scenery. Meets the 8-point "$10K" design bar (point of view,
  paired non-default type, restrained color, breathing hierarchy, intentional imagery,
  crafted motion, designed-not-shrunk mobile, WCAG AA + semantic + fast).
- **Accessibility:** WCAG 2.1 AA contrast throughout, semantic landmarks, skip link,
  visible focus rings, keyboard-friendly nav, `prefers-reduced-motion` honored.
